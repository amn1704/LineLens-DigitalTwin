# Attributions

## Visual Design Reference

The LineLens frontend took initial design direction from the publicly available
[NexusTwin](https://github.com/studio-public-demos/nexustwin-industrial-digital-twin)
showcase repository (CC BY-NC 4.0, NebulaCloud Studio). The NexusTwin download
contained a README, screenshots, and architecture illustration — no application
source code, backend, data pipeline, or runtime logic. All LineLens application
code, simulation engine, Twin estimator, prediction models, quality system,
incident engine, 3D scene, and frontend components were developed independently.
